# Artisan Dining & Culinary Masterclasses 🍽️

## About
A restaurant website showcasing fine dining, table options, food menus, and reservation pages.

## Technologies Used
- HTML5
- CSS3

## Features
- Home page
- Types of tables
- Food menu
- Booking form
- Reservation status page

## How to Run
1. Download the project.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

**Note:** Booking and reservation features are front-end demonstrations. Real reservation management requires a backend.
